# CurseBreaker Lite

CurseBreaker Lite is a mini web application built with React, Vite, React Router, and Tailwind CSS.

## Features

- Paste broken code snippets
- Select JavaScript, Python, or HTML/CSS
- View mock code diagnosis
- View corrected code
- Explain the fixes
- Copy corrected code
- Dark theme UI
- Uses mock AI data (no real API keys)

## Tech Stack

- React
- Vite
- React Router
- Tailwind CSS

## Run Locally

1. Clone the repository
2. Install dependencies

```bash
npm install
```

3. Start the development server

```bash
npm run dev
```

## Environment

Create a `.env` file if needed based on `.env.example`.

No real API keys are used.
